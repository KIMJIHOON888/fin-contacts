분류회사/기관성명직함휴대폰사무실메모
부록 D. 정리 기준 · 사용법
  • 지역 = 담당자의 지점 소재지 기준 분류(서울·경기·인천·충청·호남·영남·기타). 지점이 없거나 전국 단위면 「기타」. 각 담당자 「수정」 창에서 바꿀 수 있습니다.
  • 연락여부 = 내가 운영하는 파일(주요은행 주소록 취합)의 「마지막통화」 기록 기준. 기록이 있으면 연락함, 없으면 미연락.
  • 미연락은 다시 내 파일 등록(소개받아 적어 두었으나 통화 기록 없음)과 받은 자료만(2024 주소록·명함·전달본에만 있음)으로 구분.
  • 출처 표시: 내파일 = 운영 파일 / 2024 = 주요은행 주소록(2024.02 PDF) / 전달본 = 2026 전달본 / 명함 = 명함 정리(2026-09-28 조사).
  • 동일인은 휴대폰 번호 일치로 판단해 한 건으로 통합. 지점·직책은 가장 최근 자료 우선.
  • ★(노란 별) = 운영 파일에서 노란색으로 강조된 담당자. 이름 왼쪽 별을 누르면 즐겨찾기로 지정되고 줄이 노란색으로 바뀝니다.
  • 장점·단점·비고 칸은 줄 높이에 맞춰 잘려 보입니다. 내용이 더 있으면 칸 오른쪽 아래에 「＋더보기」가 나타나고, 누르면 전체 내용 창이 열립니다. 담당자 이름을 눌러도 같은 창이 열립니다.
  • 은행 이름 줄을 누르면 접고 펼칠 수 있습니다. 검색·필터를 걸면 결과가 있는 은행이 자동으로 펼쳐집니다.
  • 수정·추가·삭제는 이 브라우저에 자동 저장됩니다. 다른 PC·다른 사람과 쓰려면 「HTML 저장」으로 받은 파일을 전달하세요.
